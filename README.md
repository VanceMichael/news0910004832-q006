# 回调签名网关

网关接收合作来源的结果回调，完成时间窗、签名和正文摘要校验后交给内部处理器。来源、密钥版本、重试状态与审计信息写入 SQLite。

## 目录约定

- `cmd/` 为服务入口和本地示例命令。
- `internal/auth/` 处理签名和密钥版本。
- `internal/dispatch/` 处理回调投递和重试。
- `internal/store/` 负责持久化。

错误响应使用统一 JSON 结构，日志中禁止输出密钥和完整正文。测试使用内存处理器模拟下游。使用 `go run ./cmd/server` 启动，使用 `go test ./...` 运行测试。
